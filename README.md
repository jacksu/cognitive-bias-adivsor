# 认知偏差决策顾问 (Cognitive Bias Advisor)

一个帮助你在大胆决策前进行认知偏差自检的 Skill。通过十道基于经典认知偏差的诊断问题，引导你深入思考，做出更理性的决策。

## 功能

- **引导模式**：根据时间压力与决策类别，灵活选择最适配的自检深度
  - **自适应精简模式**：针对职业/学业选择、投资/重大消费、人际/情感关系、个人/日常决策四类场景，动态精选最关键的 3-5 个偏差问题，高效自检。
  - **完整十问模式**：全面自检所有 10 类经典认知偏差，进行地毯式思维盲区排查。
  - **极速模式**：针对紧急情况（<2小时），通过 3 道核心偏差诊断（确认偏误、禀赋效应、长期主义）快速通关。

- **十问框架**：依次诊断 10 种经典认知偏差
  1. 确认偏误 — 是不是只在搜支持自己的证据？
  2. 认知失调 — 如果失败，最可能因为什么？
  3. 自利性偏误 — 如果是别人，我会怎么建议？
  4. 幸存者偏误 — 是不是只看到了成功案例？
  5. 聚焦错觉 — 是不是把人生过度押注在一个变量上？
  6. 禀赋效应 — 如果今天没拥有它，还会想得到吗？
  7. 基本归因错误 — 是不是把别人的错误理解成恶意？
  8. 从众效应 — 如果没人影响我，还会这样选吗？
  9. 长期主义 — 五年后我会感谢今天的自己吗？
  10. 激励偏差 — 奖励和惩罚的机制在怎么影响我？（芒格，奖励与惩罚超级反应倾向）三大触发：聪明人集体做蠢事 / 有人给你建议 / 设计制度规则

- **智能恢复**：会话中断或网络波动时，说"继续"即可从断点接续，无需重新开始
- **决策质量评估报告**：完成后输出偏差风险摘要和行动建议
- **FAQ 常见问题**：内置偏差概念解释、使用流程、报告解读、异常恢复等常见问题集中解答

## 安装

### 方式一：ClawHub（推荐）

```bash
clawhub skill install cognitive-bias-advisor
```

安装后即可在任意对话中触发，无需额外配置。

### 方式二：SkillHub.cn

1. 访问 [SkillHub Marketplace](https://skillhub.cn) 搜索「认知偏差决策顾问」
2. 点击安装，或通过 CLI 安装：

```bash
skillhub install cognitive-bias-advisor-pro
```

### 方式三：GitHub 手动安装

```bash
# 克隆仓库
git clone https://github.com/jacksu/cognitive-bias-advisor.git

# 将 SKILL.md 和 references/ 放入你的 Agent 的 skills 目录
```

或直接下载 [最新 Release](https://github.com/jacksu/cognitive-bias-advisor/releases) 的 ZIP 包解压即可。

### 验证安装

安装完成后，在 Agent 中输入以下任意一句测试是否触发：

> "帮我决策一件事"

若进入决策引导流程，说明安装成功。

## 使用方法

### 触发方式

在任意支持 Skill 的 AI Agent 中，直接描述你的决策问题即可自动激活。以下任一关键词都会触发：

- **决策意图**："决策""决定""选择""我要不要…"
- **偏差自查**："认知偏差""决策质量""判断偏差"
- **直接请求**："帮我决策""帮我判断""十问"
- **恢复指令**："继续""接着来""重来""重新开始"

**示例触发语：**

> "我想辞职创业，帮我分析一下这个决定"

> "要不要买房，帮我决策一下"

> "我在纠结两个 offer，帮我用十问分析"

> "最近有个投资机会，不知道要不要参与"

### 使用流程

激活后，AI 会带你经历三个阶段的引导式自检：

**Phase 1 · 收集背景（2 轮对话）**
1. AI 先了解你的决策背景和初步倾向
2. 询问时间紧迫程度
3. 自动识别决策类别（职业/投资/人际/日常）
4. 推荐引导模式，你来确认

**Phase 2 · 逐题自检（3-10 题）**
- 每道题都是点击选项即可，无需长篇打字
- 一次只发一题，答完再下一题
- 三种模式可选：

| 模式 | 题目数 | 适用场景 |
|------|--------|---------|
| ⚡ 自适应精简 | 3-5 题 | 日常推荐，按决策类别匹配核心题 |
| 📚 完整十问 | 10 题 | 重大决策，地毯式排查 |
| ⏱️ 极速模式 | 3 题 | 时间 < 2 小时的紧急决策 |

**Phase 3 · 生成报告**
- 自动输出偏差风险评估
- 标注哪些维度有风险（⚠️）、哪些可控（✅）
- 给出 1-3 条具体可执行的行动建议

### 中断恢复

- 说"**继续**"或"**接着答题**" → 从断点接续，无需重答
- 说"**重来**" → 清空进度重新开始
- 说"**换个模式**"或"**分类不对**" → 中途切换，已答题目保留
- 卡住不想答了 → 连续不选选项会自动触发跳过机制

### 常见问题速查

| 问题 | 解决 |
|------|------|
| 答到一半不想答了 | 说"跳过"，或连续不选选项自动跳过 |
| 选错了类别/模式 | 说"换个模式"或"分类不对"，随时切换 |
| 某题不知道怎么答 | 选"✍️ 我想补充说明"，用一句话描述想法 |
| 只有 2 小时时间 | Phase 1 选"⏱️ 极速模式"，只答 3 道核心题 |
| 完整十问要多久 | 通常 5-8 分钟，点击选项即可无需打字 |
| 对某个偏差概念不懂 | 随时问"什么是确认偏误"之类的，直接获得解释 |

## 注意事项

- 本技能的目的是**辅助思考**，不是代替你做决定
- 对时间极度紧迫的决策（<2小时），可跳过部分问题
- 保持开放心态，诚实回答每个问题效果最佳
- 遇到中断或卡顿，输入"继续"即可从断点恢复；输入"重来"清空重新开始
- 对偏差概念不理解？随时问"什么是XXX"即可获得解释
