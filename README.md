# 认知偏差决策顾问 (Cognitive Bias Advisor)

一个帮助你在大胆决策前进行认知偏差自检的 CodeBuddy Skill。通过九道基于经典认知偏差的诊断问题，引导你深入思考，做出更理性的决策。

## 功能

- **引导模式**：根据时间压力与决策类别，灵活选择最适配的自检深度
  - **自适应精简模式**：针对职业/学业选择、投资/重大消费、人际/情感关系、个人/日常决策四类场景，动态精选最关键的 3-4 个偏差问题，高效自检。
  - **完整九问模式**：全面自检所有 9 类经典认知偏差，进行地毯式思维盲区排查。
  - **极速模式**：针对紧急情况（<2小时），通过 3 道核心偏差诊断（确认偏误、禀赋效应、长期主义）快速通关。

- **九问框架**：依次诊断 9 种经典认知偏差
  1. 确认偏误 — 是不是只在搜支持自己的证据？
  2. 认知失调 — 如果失败，最可能因为什么？
  3. 自利性偏误 — 如果是别人，我会怎么建议？
  4. 幸存者偏误 — 是不是只看到了成功案例？
  5. 聚焦错觉 — 是不是把人生过度押注在一个变量上？
  6. 禀赋效应 — 如果今天没拥有它，还会想得到吗？
  7. 基本归因错误 — 是不是把别人的错误理解成恶意？
  8. 从众效应 — 如果没人影响我，还会这样选吗？
  9. 长期主义 — 五年后我会感谢今天的自己吗？

- **决策质量评估报告**：完成后输出偏差风险摘要和行动建议

## 使用方法

在 CodeBuddy 中直接描述你的决策问题即可触发，例如：

> "我想辞职创业，帮我分析一下这个决定"

> "要不要买房，帮我决策一下"

> "我在纠结两个 offer，帮我用九问分析"

## 注意事项

- 本技能的目的是**辅助思考**，不是代替你做决定
- 对时间极度紧迫的决策（<2小时），可跳过部分问题
- 保持开放心态，诚实回答每个问题效果最佳
